# Additional Requirements & Workflow Specification

## User Roles

### 1. Super Admin

Full control.

Permissions:

* Create/Edit/Delete users
* Assign roles
* Product master management
* QR generation
* System settings
* Tally configuration
* View all reports
* Export data
* Reprocess failed Tally transactions
* Backup and restore

---

### 2. Admin

Permissions:

* View all stock
* View reports
* Generate QR codes
* Manage products
* View transaction logs

Cannot:

* Delete historical transactions
* Change system settings

---

### 3. Purchase User

Permissions:

* Receive stock
* Scan QR
* Create inward entries
* View own transactions

Cannot:

* Delete entries
* Access sales functions

---

### 4. Sales User

Permissions:

* Scan products
* Dispatch stock
* Mark sold stock
* View own transactions

Cannot:

* Modify purchase entries

---

### 5. Auditor

Permissions:

* Perform stock verification
* Scan products
* Generate audit reports

Cannot:

* Create purchase entries
* Create sales entries

## Product Workflow

### Product Creation

Admin creates:

```text
Product Code
Product Name
HSN
GST
Unit
```

Example:

```text
SG001
Turmeric Powder 100g
0910
5%
PCS
```

---

## QR Generation Workflow

Admin selects:

```text
Product
Quantity
```

Example:

```text
Turmeric Powder
1000 Units
```

System generates:

```text
SG001-000001
SG001-000002
...
SG001-001000
```

Generate:

* QR Image
* PDF Labels
* Excel Export

---

## Stock Receiving Workflow

Purchase User

Step 1:
Login

Step 2:
Open Scanner

Step 3:
Scan QR

Example:

```text
SG001-000501
```

Step 4:
Confirm

System records:

```text
User
Date
Time
Action = RECEIVE
```

Step 5:

Update Tally automatically.

---

## Sales Workflow

Sales User

Step 1:
Login

Step 2:
Scan QR

Example:

```text
SG001-000501
```

Step 3:
Confirm Sale

System records:

```text
Action = SOLD
Date
Time
User
```

Step 4:

Send transaction to Tally.

---

## Audit Workflow

Auditor

Step 1:
Start Audit Session

Step 2:
Scan available stock

Step 3:
Complete Audit

```text
Expected Stock

Scanned Stock
```

Generate:

```text

Extra Items
Verified Items
```

```text

↓

↓
SOLD
```

## Tally Integration Workflow

### Receive



in Tally.

---

### Sale

Scan:

```text
SG001-000501
```

Create:

```text
Stock Issue Entry
```

```text

```
