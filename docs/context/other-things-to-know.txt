Revised Developer Requirement Document

Project: QR Scan Bridge for Tally Prime

Objective

Develop a simple, fast, lightweight web application that uses mobile phones to scan QR codes on products and automatically update Tally Prime.

The application is not an inventory system.

The application is not a billing system.

The application is not an ERP.

Tally Prime remains the primary system for:

Stock management

Inventory records

Accounting

Purchase entries

Sales entries

Reports


The app acts only as a QR scanning and transaction capture layer between users and Tally.


---

Core Workflow

Product QR Code
       ↓
Phone Camera Scan
       ↓
Web App
       ↓
Python Backend
       ↓
Tally Prime XML API
       ↓
Tally Updated


---

Project Goals

1. Eliminate manual stock entry.


2. Allow stock movement using phone camera scans.


3. Maintain scan history.


4. Update Tally automatically.


5. Minimize user actions.


6. Simple UI suitable for warehouse staff.


7. Fast performance.


8. Low development cost.


9. Easy future expansion.

User Roles

Admin

Can:

Create users

Reset passwords

View scan logs

Configure Tally connection

View system status


Cannot directly modify transaction history.


---

Purchase User

Purpose:

Receiving stock.

Actions:

Scan product QR

Submit receive transaction


Result:

Stock receipt posted to Tally.


---

Sales User

Purpose:

Dispatch/sales confirmation.

Actions:

Scan product QR

Submit sale transaction


Result:

Stock reduced in Tally.


---

Auditor

Purpose:

Physical verification.

Actions:

Scan product QR

Mark as verified


Result:

Audit trail stored.

No stock changes in Tally.


---

QR Code Specification

Each product unit or carton will have a unique QR code.

Example formats:

SG001-000001
SG001-000002
SG001-000003

or

SG-CHILLI-100-000001

QR should contain only the unique serial number.

No pricing data.

No GST data.

No customer information.

Final MVP Statement

A browser-based QR scanning system where Purchase, Sales, and Audit users scan product QR codes using their phone camera, the scan is logged, and the corresponding stock movement is automatically updated in Tally Prime through XML integration.
